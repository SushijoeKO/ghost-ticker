# Ghost Ticker

Spy-console news wire (Next.js 16 + Tailwind 4). © 2026 SushijoeKO. All rights reserved.

- Switches: `lib/config.ts` — `LAUNCHED` (noindex + robots disallow while false), `ADS.ADS_ENABLED` (false), `ADS.TEST_MODE` (true), `ADS.SLOTS`.
- Sources: `lib/sources.ts` (192 news feeds plus 8 satire feeds on the Disinfo Desk). Validation notes are in `docs/feed-validation.md`.
- Feed engine: `lib/feeds.ts` — 20 feeds at a time, 8 s per-feed timeout, 45 s cycle budget, ISR revalidate 300 s. A failed or slow feed is skipped and cannot abort the sweep.
  Jaccard/containment title dedupe (other outlets listed under "+N more outlets"), breaking = hard-news + recency + keywords
  (or 3+ outlets within 1 h), per-outlet caps, left/right/center round-robin for politics.
- Only headline, outlet, time, ≤160-char feed snippet and outbound link are shown. No images, no article bodies.
- Local: `npm ci && npm run build && npx next start -p 3100`; QA: `cd tests && ln -sfn /tmp/nd-live-qa/node_modules node_modules && node qa.mjs`
  (Playwright 1.65; needs real network for feeds).
- Deploy: files are uploaded with Vercel MCP `upload_file` (SHA refs in `deploy-refs.json`) then `create_deployment`
  (project ghost-ticker, target production, framework nextjs, nodeVersion 24.x). Project protection: Vercel Authentication, all deployments.

## v3 thumbnails (Nov 8, 2026)
- Photo order per story: its feed image → a cluster-mate outlet's feed image → an image found by an earlier sweep (`gt_headlines.image`) → the article's own `og:image` / `twitter:image` (`lib/ogimage.ts`, `lib/images.ts`).
- Article lookups are server-side only, with a polite UA, 3.5 s timeout, 6 at a time, a 9 s budget per render, and reads stop at `</head>`. Results are cached in memory for 6 h and saved to the archive. Image URLs are checked (http(s), `image/*`, no same-origin CORP). Images are still hotlinked with `referrerpolicy=no-referrer`; nothing is rehosted.
- CDNs that refuse embedding (`lib/hotlink.ts`: UPI, NDTV) are never used. Sites that block bots (NPR, Washington Post and RealClearPolitics answer 403 or time out) fall back.
- Every photo sits in a fixed aspect-ratio frame: 16:9 for leads, 4:3 for side thumbs. Frames are top-aligned (never stretched by the row) and use `object-fit: cover` with `object-position: center 30%`. A failed load swaps in a compact "NO VISUAL" mark inside the same frame, so the layout doesn't move. Lead cards and the top story go text-only when there is no photo, and section leads prefer a photo among the top 4.
- Decrypt effect: the real headline text is never modified. The scramble is an `aria-hidden` overlay that is always removed by a timer, on tab hide or pagehide, or on unmount.
- Tests: `tests/qa-v3-thumbs.mjs` checks frames at 375/768/1280 on home, category, search, trending and map, plus onerror/CLS, decrypt and leads. `tests/measure-thumbs.mjs` measures photo coverage.

## v2 features (Nov 8, 2026)

- **Photos**: uses only the image the feed provides (media:content / media:thumbnail / media:group / enclosure / first `<img>`), hotlinked with `referrerpolicy="no-referrer"` and `loading="lazy"`; never rehosted or cropped. Missing or broken images fall back to a generated "case file" placeholder with the outlet's initials. CDNs that refuse cross-site embedding (UPI, NDTV) are skipped on purpose (`NO_HOTLINK` in `lib/feeds.ts`).
- **Live map**: `/map` plus a home-page mini-map. `public/world.svg` and `lib/gazetteer.json` are generated by `python3 scripts/build-geo.py` from Natural Earth 1:110m (public domain). `lib/places.ts` picks the most specific place and skips ambiguous names (Georgia, Jordan, Paris…) unless context supports them.
- **Spy flair**: decrypt effect, CRT scanlines/glow toggle (`gt-crt`), tap/hover redaction bars, clearance badges (L1 1 outlet / L2 2–3 / L3 4+), "new intel" toast, optional Web Audio alert (OFF by default, `gt-sound`). All motion is disabled under `prefers-reduced-motion`.
- **Tags** (`lib/tags.ts`): original snark tags (SUSPICIOUS, BURN NOTICE, ROGUE AGENT, DOUBLE AGENT, COVER BLOWN, ASSET ACQUIRED, NEED-TO-KNOW, OBVIOUSLY, WTF-INT, FLORIDA FILE, CRITTER-INT, GADGET-INT, PAPER TRAIL, EXFIL, MOLE HUNT, HONEYPOT, SAFEHOUSE). Anything about death, violence, disaster, abuse, terror, serious illness or harm to children gets only a neutral FLASH / PRIORITY tag (or none). Covered by `node --test tests/unit.test.mjs`.
- **Videos**: `lib/videos.ts` reads public YouTube channel RSS feeds of 15 outlets (left, center, right, international). Only the thumbnail loads until the visitor presses play; then a `youtube-nocookie.com` iframe is created.
- **Search / votes / trending**: Supabase project `cljswcafyqvtbtqsbfzs`, tables `gt_headlines` and `gt_votes`. The browser only talks to this site's `/api/vote` and `/api/pulse`; pages call Supabase server-side.

### Pinning X posts

Edit `pinned-posts.json` and add public post URLs to `posts`, then redeploy:

```json
{ "posts": [ { "url": "https://x.com/someaccount/status/1234567890123456789", "note": "Optional label" } ] }
```

Only `https://x.com/<user>/status/<id>` or `twitter.com` URLs are accepted (max 6). Nothing loads from X until a visitor presses "Load post from X" (X may set cookies then). No X API key or account is used. The `_example` entry is never rendered; with an empty list the section is hidden.

### Environment variables (Vercel project `ghost-ticker`, production + preview)

| Key | Use |
| --- | --- |
| `SUPABASE_URL` | Supabase project URL (server only) |
| `SUPABASE_ANON_KEY` | Supabase publishable key (server only; RLS keeps it read-only) |
| `GT_INGEST_KEY` | Secret for the `gt_ingest` RPC; only its SHA-256 is stored in the DB (`gt_private.ingest_key`) |

Local dev reads them from `.env.local` (gitignored, never uploaded). To rotate the ingest key: generate a new value, update it in Vercel, and run `update gt_private.ingest_key set hash = encode(extensions.digest('<new>','sha256'),'hex');`.

### Supabase migrations

- `gt_create_archive_and_votes`: `gt_headlines`, `gt_votes`, `gt_private.ingest_key`, RPCs `gt_ingest`, `gt_vote`, `gt_search`, `gt_trending`, with RLS.
- `gt_fix_ingest_filter`: tightened `gt_ingest` row validation (bad rows are always dropped; non-https images are nulled).
